## 📌 O que é o NexusAI Recruit?

O **NexusAI Recruit** é uma plataforma SaaS (Software como Serviço) de **triagem inteligente de candidatos** desenvolvida para departamentos de Recursos Humanos (RH) e empresas de recrutamento.

> 💡 **Em linguagem simples:** Imagine que sua empresa recebeu 300 currículos para uma vaga. Em vez de uma pessoa ler cada um manualmente, o NexusAI Recruit usa Inteligência Artificial para analisar todos os candidatos automaticamente, dando uma nota, identificando os melhores perfis e exibindo tudo em um painel visual bonito e fácil de entender.

## ✨ Funcionalidades Principais

### 🧠 Análise por Inteligência Artificial
- Cada candidato recebe uma **pontuação de 0 a 100** baseada em seu perfil
- A IA analisa competências técnicas, soft skills e compatibilidade com a vaga
- Classificação automática: ✅ Aprovado | ⏳ Em revisão | ❌ Rejeitado

### 📊 Dashboard Completo
- **Cards de métricas** com total de candidatos, taxa de aprovação e tempo médio
- **Gráfico de Pizza** mostrando distribuição por status
- **Gráfico de Área** com tendência de candidatos ao longo do tempo
- **Gráfico Radar** com análise de habilidades individuais

### 👥 Gestão de Candidatos
- Lista completa com foto, nome, cargo, localização e pontuação
- Filtros por status (aprovado, em revisão, rejeitado)
- Busca em tempo real por nome ou cargo
- Perfil detalhado de cada candidato com clique

### 🔍 Perfil Detalhado do Candidato
- Histórico profissional completo
- Competências técnicas com barras de progresso
- Gráfico radar de habilidades comportamentais
- Anotações e comentários do recrutador
- Botões de ação: Aprovar / Rejeitar / Agendar Entrevista

### 🌙 Modo Escuro / Claro
- Interface adaptável às preferências do usuário
- Salva automaticamente a preferência escolhida

## 🗺️ Navegando pela Plataforma

### Passo a Passo para Iniciantes:

**1. Tela Inicial (Dashboard)**
- Ao abrir, você verá os **4 cards de métricas** no topo (total de candidatos, aprovados, tempo médio, vagas)
- Abaixo, os **gráficos** mostram visualmente os dados
- Na parte inferior, a **lista de candidatos recentes**

**2. Ver Lista de Candidatos**
- Clique em **"Candidatos"** no menu lateral esquerdo
- Use a barra de **busca** para encontrar alguém pelo nome
- Use os **filtros de status** para ver só aprovados, só em revisão, etc.

**3. Ver Perfil de um Candidato**
- Clique em qualquer candidato da lista
- Um painel lateral abrirá com **todas as informações detalhadas**
- Veja a pontuação, habilidades, experiência e o gráfico radar

**4. Ações sobre o Candidato**
- Botão verde ✅ = **Aprovar** o candidato
- Botão vermelho ❌ = **Rejeitar** o candidato  
- Botão azul 📅 = **Agendar entrevista**

**5. Alternar Tema**
- Clique no ícone 🌙/☀️ no canto superior direito para mudar entre modo escuro e claro
